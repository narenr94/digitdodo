<h1 align="center">DigitDodo</h1>
<p align="center"><i>Middleware for digit displays with blink and scroll capabilities</i></p>

---

## 🌟 Overview

**DigitDodo** is a lightweight middleware designed to enhance digit-based displays with dynamic features like blinking and scrolling. It integrates seamlessly with async schedulers like `TickToucan`, making it ideal for bare-metal systems and embedded applications.

---

## 🔧 Features

- Blink and scroll modes for 7-segment or custom digit displays
- Scheduler-aware design for non-blocking execution
- Minimal footprint, no dynamic memory
- Easy integration with `TickToucan` or other async engines
